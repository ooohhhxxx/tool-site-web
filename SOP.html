调试工具
标准操作程序（SOP）

文件编号：SOP-UTW-001 ｜ 版本：V0.4.12 ｜ 生效日期：2026-11-08 ｜ 编制：工具开发组

一、目的

为规范「调试工具」（以下简称"本工具"）的安装、配置与日常使用，确保操作人员能够正确、安全地完成 SSH 远程管理、Modbus TCP 通信调试与串口设备调试，降低误操作风险，提高排障效率，特制定本 SOP。

二、适用范围

  • 需要同时管理 SSH 主机、Modbus TCP 设备与串口设备的现场调试、运维、产线排障场景；
  • Windows 10 / 11 x64 桌面环境；
  • 本工具与「经典 Tk 版调试工具」是两个独立软件，可同时安装、互不影响。本 SOP 只适用于桌面版 v0.2.0。

三、运行环境要求

项目要求
操作系统Windows 10 / 11，64 位
运行时Microsoft Edge WebView2 Runtime（Win10/11 通常随系统或 Edge 预装；缺失时窗口会白屏或无法启动）
网络本机回环 127.0.0.1 可用；程序默认自动选择空闲端口，不要求联网
磁盘安装后约 50 MB（onedir 目录），安装包约 21 MB
权限普通用户权限即可安装（安装脚本使用 PrivilegesRequired=lowest）
💡 程序启动后会在本机起一个 uvicorn 服务并由原生 WebView2 窗口访问它，服务只绑定 127.0.0.1，外部机器访问不到；关闭窗口即停服务并退出进程。

四、安装、升级与卸载

4.1 首次安装

  1. 从官网下载 UltimateToolWeb-Setup.exe，建议核对版本清单 version.json 中的 SHA256。
  2. 双击安装包，按向导完成；可勾选「创建桌面快捷方式」。
  3. 默认安装到 C:\Program Files (x86)\UltimateToolWeb（或 Programs 目录），AppId 与经典 Tk 版不同，不会覆盖旧软件。
  4. 安装完成可直接勾选「立即启动」。

4.2 升级（推荐：在线更新）

  1. 打开「设置」页，软件更新区在启动时会按设置自动检查一次线上版本清单；也可随时点「检查更新」手动触发。
  2. 发现新版本后显示版本号、包大小与更新说明，点「下载更新」。程序按国内镜像优先的顺序尝试多个下载源，某个源失败会自动换下一个，界面显示进度百分比。
  3. 下载完成后自动做 SHA256 校验，校验不通过会丢弃文件并报错，不会安装坏包；通过后按钮变为「立即安装」。
  4. 点「立即安装」会启动安装向导，并自动关闭本程序（覆盖安装要求旧进程先退出）。按向导完成即可。
  5. 也可手动到官网下载新安装包，运行后安装到相同目录覆盖升级，无需先卸载（AppId 未变）。
💡 用户数据（连接记录与已加密的密码、窗口几何、插件开关）都存放在用户目录，覆盖安装不会清除。在线更新只使用 127.0.0.1 之外的官网/Gitee 地址，不会上传任何本机配置。

4.3 卸载

通过「设置 → 应用 → 安装的应用」或开始菜单的「卸载」入口执行。卸载不会删除用户目录下的配置与日志文件，需要彻底清理时手动删除第十节列出的路径。

⚠️ 本软件未购买数字签名证书，Windows Defender / 360 等可能误报，请先核对 SHA256 再添加信任。

五、启动、单实例与运行原理

  1. 双击桌面图标或开始菜单「调试工具」。
  2. 启动器先补好无控制台环境下的标准输出流，随机选一个本机空闲端口，后台线程启动 uvicorn。
  3. 主线程创建 WebView2 原生窗口（标题「调试工具」），加载本机前端页面。
  4. 关闭窗口 → 停服务 → 清理单实例登记 → 进程退出（实测退出码 0）。

5.1 单实例

程序用 Windows 命名互斥体保证只跑一个主实例。再次双击图标时不会新开进程，而是把已有窗口还原、前置后退出；若已有窗口被最小化，会被恢复显示。这样可避免两个进程共用 WebView2 配置目录、互相覆盖连接记录，以及争抢同一个串口 COM 口。

💡 确实需要两个窗口并排时，可用命令行设置环境变量 UTWEB_NEW_INSTANCE=1 再启动。该实例会使用独立的 WebView2 配置目录，连接记录不与主实例共享。

5.2 常用环境变量（调试 / 自动化）

变量作用
UTWEB_PORT固定服务端口，不设则自动选空闲端口
UTWEB_SHELLwindow（默认）/ browser / headless
UTWEB_NO_BROWSER=1 等价 headless，只跑服务不弹窗口
UTWEB_NEW_INSTANCE=1 强制再开一个实例
UTWEB_INSTANCE_TAG隔离互斥名、登记文件与 WebView2 配置目录，供自动化测试使用
NO_PROXY启动器会自动设为 127.0.0.1,localhost，避免本机 WebSocket 握手被系统代理拦截

六、SSH 远程管理操作流程

  1. 左侧点「SSH 远程管理」，右上「新建主机」，填写主机、端口、用户名、密码（或私钥）与编码，确认连接。
  2. 连接成功后新增一个会话标签；多个主机可同时保持多个标签，点标签切换，标签上的 × 关闭单个会话。
  3. 中间深色区域是 xterm 终端，直接键入命令；支持选中复制、Ctrl+滚轮或设置页缩放字号、清屏。
  4. 右侧「远程文件」面板可列目录、过滤、上下载、新建目录、删除、返回上级；路径栏可直接输入跳转。右键文件可「查看 / 编辑」（直接读写远端文本文件，超过 2 MB 会提示下载后本地编辑；保存时先写临时文件再替换，断线不会截断原文件）、重命名、修改权限（八进制，如 644 / 755）、删除与刷新目录。
  5. 终端与文件面板之间的竖直分割条可拖动改宽度，双击恢复默认 62%；窗口过窄时自动改为上下堆叠。
💡 部分交换机 / 工控机没有安装 sftp-server，此时 SFTP 会建立失败，程序会自动降级为纯终端，终端仍然可用，文件面板显示「未连接或 SFTP 不可用」属正常现象。
💡 连接记录已保存密码：新建主机时填一次密码即可，左侧选中记录后点「连接选中记录（免密）」或双击记录直接连接，不用每次重输。密码用 Windows DPAPI 加密存在本机用户目录，前端列表接口不回显任何凭据。右键记录可打开「连接 / 编辑记录 / 删除记录」菜单；编辑时可改主机、端口、用户名、密码、编码与备注，密码留空表示沿用已保存的密码。未保存密码的记录会提示先编辑补上。
⚠️ 在终端执行 rm、reboot、shutdown 等破坏性命令前，务必反复确认目标主机与路径，防止误操作生产环境。

七、Modbus TCP 调试操作流程

  1. 左侧点「Modbus TCP」，填写设备 IP、端口（默认 502）、超时后点「连接」。
  2. 「快速读写」区选择功能码与地址，执行单次读 / 写；写入前请确认地址含义。
  3. 添加监控点位后可批量轮询，当前值与变化在表格中显示；双击「备注」列可改名（默认是「点位 N」，现场点位多时建议按用途命名）；报文日志记录每帧交互，便于对线。
  4. 左右分栏之间有可拖动分割条，双击恢复默认 58%。
🚨 安全红线：对运行中的设备（尤其是控制物理动作的 PLC）写入任何线圈或寄存器前，必须与现场人员确认地址含义。擅自写入可能导致设备动作或生产事故！

八、串口调试操作流程

  1. 左侧点「串口调试」，点「刷新端口」枚举本机 COM 口，选择端口、波特率、数据位、校验位、停止位与编码，点「打开串口」。
  2. 在发送区输入内容，可选 HEX 模式（字节用空格分隔）、自动换行、定时循环发送；Ctrl+回车 直接发送。
  3. 接收区实时显示，可切换 HEX / 文本视图、暂停、自动滚动、清空；底部显示 TX / RX 字节计数。
  4. 左右分栏之间同样有可拖动分割条，双击恢复默认 50%。
⚠️ Windows 的串口是独占资源。若提示「端口被占用」，请关闭其他串口助手、PLC 编程软件，或确认没有第二个本工具实例在跑（见 5.1）。循环发送间隔建议不小于 50ms。

九、插件功能

  1. 左侧点「插件」，页面列出已发现的插件、版本、状态与说明。
  2. 用开关启用 / 停用插件；选中插件后双击命令即可执行，长任务可点「停止」。
  3. 执行日志通过 WebSocket 实时推送到页面下方。
  4. 用户插件目录 ~/.ssh_gui_plugins 优先级高于内置目录，同名插件可覆盖。
💡 内置 3 个示例插件共 9 个动作：SSH 批处理、Modbus 扫描、串口 HEX。插件沿用经典 Tk 版的 PluginBase 契约，已有插件可直接复用。

十一、故障排查

现象排查方向
双击没反应 / 弹错误框查看 ~/ultimatetool_web_launcher.log；确认没有其他进程占用端口；必要时设 UTWEB_PORT 固定端口重试
窗口白屏确认系统已安装 Microsoft Edge WebView2 Runtime；检查杀毒软件是否拦截了本机回环连接
提示端口被占用关闭其他实例；或设 UTWEB_PORT 换一个固定端口
本机连接被代理拦截 / WebSocket 502启动器已自动设置 NO_PROXY=127.0.0.1,localhost；如自行改写环境变量请勿覆盖
串口打不开见第八节，确认无其他软件占用 COM 口
连接记录 / 窗口大小没记住确认用户目录可写；逃生口多开的第二个实例使用独立配置目录，不共享记录

十二、安全与合规

  • 程序不访问外网、不上传任何连接信息或设备数据，全部通信由操作人员主动发起；
  • 对生产设备执行写操作（Modbus 写入、SSH 破坏性命令、串口控制指令）前必须双人确认；
  • 删除远程文件不可恢复，删除前逐字核对完整路径；
  • 本软件为个人免费工具，无数字签名，请从官方仓库核对 SHA256 后再分发。

十三、已知限制

  • 依赖系统 WebView2 Runtime；老机器可能需要单独安装 Evergreen Bootstrapper。
  • 在线更新已内置；托盘最小化、全局快捷键、文件关联与命令行传参暂未实现。
  • 设置页部分开关为原型占位（见第十节）。
  • 在线更新依赖能访问官网或 Gitee；完全离线的环境请手动下载安装包覆盖升级。
  • 未做 WebView2 Runtime 的随包分发，离线纯净系统需提前准备运行时。
