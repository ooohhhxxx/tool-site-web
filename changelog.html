v1.0.0 2026-11-19 上一版
新增
场景编排：把「SSH 看状态 → Modbus 读状态字 → 串口问一句 → HTTP 查平台」串成一条场景，一键复跑。十种步骤（SSH 执行 / Modbus 读写 / S7 读写 / OPC UA 读写 / 串口收发 / HTTP GET / 等待），每步可设断言（等于/不等于/区间/包含/正则等十二种）、重试、单步超时、失败是否继续；上一步取到的值可存成变量，用 ${名称} 传进后面的地址或 URL。跑完给出逐步结果与 Markdown 报告（可直接贴工单），运行历史保留最近 200 次。
新增
诊断知识库：把「现象 → 原因 → 处置」沉淀成可搜索条目，内置 16 条现场真踩过的坑——SFTP 子系统缺失（EOF during negotiation）、paramiko 4 移除 SHA-1 系算法、RTU 超时、Modbus 02/03 异常码、CRC 干扰、COM 口被占用、S7 rack/slot 与优化块、OPC UA 证书不受信、串口无回包等。场景某步失败时会自动按报错文本匹配，把最可能的原因和处置直接贴在结果旁边。可自己增删条目，内置条目不可修改（升级不会被覆盖），点「编辑」会转成自己的版本。
新增
OPC UA 加密通道与订阅：支持 Basic256Sha256 / SignAndEncrypt——客户端证书首次使用自动生成（带 SAN，兼容 S7-1500、Kepware 这类严格校验），把 client.der 导入设备信任列表即可；服务端证书必须自己指定并校验有效期，不自动接受自签证书、不静默降级到不加密。数据订阅最多 100 个节点、周期 0.1–60 秒，变化实时滚动（留最近 200 条），停止订阅或断开时会把服务端订阅一并删掉。
说明
场景步骤只调用已经连好的连接，不会替你把设备凭据存进场景文件；写入类步骤仍受只读模式拦截、仍进审计。目前只支持线性步骤，没有循环与分支；HTTP 步骤为 GET。左侧导航从九个页面增加到十一个（Ctrl+1~9 仍对应前九个）。OPC UA 的用户名密码仍允许在未加密策略下使用（部分设备只支持 None），界面会明确提示「凭据将明文传输」。
v0.7.1 2026-11-18
新增
OPC UA：连接后可逐层浏览节点树，点节点直接读值（含数据类型、状态码、时间戳）；变量节点可写值，写入按节点当前类型自动转换——布尔认 true/false，整数支持 0x 前缀。适用于 S7-1500、SCADA、仪表网关等支持 OPC UA 的设备。写入同样进审计、同样受只读模式拦截。
新增
Modbus RTU / ASCII：Modbus 页连接卡片新增传输方式下拉，可直连串口从站（电表、变频器、温控器）。串口/波特率/数据位/校验/停止位可配，参数随表单保存，重启后保持。
说明
串口调试是「收发原始字节」，RTU/ASCII 是「按协议读写寄存器」——两者共用同一个 COM 口但不能同时打开；排障时可用串口页看原始回波，快速分清接线问题和地址问题。安装包因 OPC UA 依赖增加约 1.9MB。暂未支持 OPC UA 加密通道（需证书分发）、订阅推送、方法调用与历史数据。
v0.6.0 2026-11-18
新增
审计日志：以前改完 PLC 或寄存器，出问题只能靠回忆「刚才谁改的、原来是多少」。现在每次写入都留一条记录——Modbus / S7 会先读一次原值，记下「改前 → 改后」、结果与失败原因；SFTP 的删除 / 重命名 / 改权限 / 保存 / 上传、串口发送、SSH 远程命令也一并留痕。默认保留 90 天，只存本机。
新增
只读模式：一个开关拦下所有设备写入与远程文件修改，适合培训、陪产、远程指导这类「只看不动」的场景。开启需二次确认，状态跨重启保持，误触写入时会直接提示去哪里关闭。
边界
SSH 交互式终端不拦截——终端里读命令和写命令无法从字节流区分，拦了连 ps、cat 都用不了，排障会直接断掉。这条边界写在页面说明与 SOP 里，由操作人自律。串口「循环发送」做了节流，同内容 1 秒内只记一条。

v0.5.0 2026-11-18
重要更新
新增「采集监控」页面：以前四个调试模块都是「连上、看一眼、断开」，值读完就没了——现场偶发故障等你赶到时已经恢复，手上没有任何证据。现在可以把 Modbus / S7 点位加入监控列表，设定各自采样周期（最快 200ms），后台持续采集并落盘到本地数据库；值不变也照常记录，因此能看出「值卡住不刷新」这类隐性故障。
新增
历史趋势曲线：选中点位即可看 10 分钟 / 1 小时 / 6 小时 / 1 天 / 7 天的历史曲线；数据量大时自动按时间桶聚合成平均值与上下界，查询 7 天也不会卡。
新增
阈值告警：每个点位可配一条条件（大于 / 小于 / ≥ / ≤ / 等于 / 不等于 / 超出范围）、级别（提示·警告·严重）、冷却时间与自定义消息；触发后进入告警列表并按级别着色，支持单条或全部确认。冷却机制避免持续越限刷屏。
说明
数据保存在本地单文件数据库（原始采样 7 天、告警 30 天，到期自动清理），不上传任何数据。采集复用现有 Modbus / S7 连接，未连接时记为错误并在统计里显示，不影响其它功能；串口无地址概念，暂不参与数值采集。导航新增 Ctrl+7 快捷切页。

修复
「一直更新失败」：两个缺陷叠在一起。① 下载被中断时 read() 只是返回空、循环正常退出，于是半截文件被当成下载完成，接着 SHA256 自然不匹配，把「网络断了」误报成「校验不通过」；② 同一个源失败后直接换下一个，不做重试，三个源轮流挂掉就彻底失败。

v0.4.9 2026-11-07
修复
连一台响应慢的设备会让整个程序卡死：实测连一个要 8 秒才超时的地址，期间其它请求要等 7.5 秒才有响应——终端不出字、切页点不动、串口数据也停。原因是后端 54 个接口都写成异步函数，内部却在跑同步阻塞的网络调用（paramiko / pymodbus / pyserial），把整个事件循环占住了。现在阻塞型接口改到线程池执行，同样场景下其它请求 13 毫秒就返回。

终端大数据量输出合并成帧：cat 大文件或 dmesg 时不再一帧一帧地推，按 256KB 上限合并后再发，终端渲染更连贯。
